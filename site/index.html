Architecture

A real kernel, not decorative chrome.

Apps never import each other — they call kernel services and talk over an intent bus. That’s what makes it feel like one product.

🪟

Window manager

Open, focus, tile, minimize, maximize — with cascade placement and workspace persistence.

🔌

Intent bus

Typed pub/sub + request/response. Cross-app actions are intents, never direct imports.

🗃️

Virtual file system

IndexedDB-backed, shared across Files, Code, Notes and the AI agents’ tool calls.

🎨

Design tokens

Dark-first tokens that inherit through Shadow DOM. Accent, wallpaper and scaling all live.

✳

Local AI runtime

Multi-agent orchestration with streaming and tool calls — cloud runtime arriving as a phase.

🧩

App SDK

Every app — first-party or plugin — implements one capability-scoped contract.
