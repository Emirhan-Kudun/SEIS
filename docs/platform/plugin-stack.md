# SEIS Plugin Stack

## Product Build

| Area | Plugins |
|---|---|
| Android | Expo, Test Android Apps |
| Web | Build Web Apps, Browser, Vercel |
| macOS | Build macOS Apps |
| Full-stack | Convex, Supabase, Vercel |
| Data | Data Analytics, Google Drive |

## Operations

| Area | Plugins |
|---|---|
| Repository control | GitHub, SEIS plugin |
| Scheduling | Google Calendar |
| Knowledge base | Google Drive |
| Documents | Documents, Google Docs through Drive |
| Dashboard/reporting | Data Analytics |

## Rules

- Use plugin-specific workflows when they exist.
- Keep SEIS repo docs as source of truth after external tool actions.
- Do not let external artifacts replace GitHub records.
- Avoid deleting old repositories or refs from plugin workflows unless SEIS gates pass.
