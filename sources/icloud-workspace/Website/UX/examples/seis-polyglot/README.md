# SEIS Polyglot Surface

Small language adapters that keep the GitHub language graph broad without adding production dependencies.

These files are intentionally tiny and do not run in the main build. They document how SEIS can speak across web, native, backend, automation and systems contexts while preserving the primary TypeScript/Next.js runtime.

Current examples cover HTML, CSS, JavaScript, JSON, TypeScript, Swift, Kotlin, Python, Go, Rust, PHP, C#, Java, Shell, SQL, C++, Docker, Terraform, Vue, Astro and Svelte.
