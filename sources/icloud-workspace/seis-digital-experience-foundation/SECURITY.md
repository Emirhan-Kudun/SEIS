# Security Policy

## Supported Versions

The repository is currently maintained under an active development workflow.

| Version | Supported |
| ------- | ---------- |
| v1.x    | Accept |
| v0.x    | Refused |

---

## Reporting a Vulnerability

If you discover a security vulnerability, please report it responsibly through GitHub Issues or private repository communication channels.

Please include:
- vulnerability description
- reproduction steps
- affected components
- possible impact

Security-related reports will be reviewed as quickly as possible.

---

## Security Principles

This repository follows a security-oriented engineering workflow focused on:

- protected branches
- reversible changes
- clean dependency management
- AI-assisted workflow safety
- minimal attack surface
- repository governance
- scalable maintainability

---

## Notes

Do not publish sensitive credentials, API keys or private infrastructure data in issues, pull requests or discussions.
