# Conventions

- SEIS rules from `AGENTS.md`: calm, modular, high-efficiency AI-native creative-engineering system.
- Prioritize clarity, maintainability, accessibility, scalability, rollback safety, compositional quality, humane UX, cognitive sustainability, performance efficiency, modular architecture, and observability.
- Use proportional orchestration: small tasks lightweight, medium tasks scoped, large tasks phased.
- Design language: cinematic minimalism, editorial hierarchy, restrained elegance, whitespace intelligence, atmospheric clarity, calm pacing, premium typography.
- Motion: restrained, supports `prefers-reduced-motion` and explicit low-motion mode; avoid GPU-expensive/mobile-heavy effects.
- Legacy files must be analyzed before migration and not copied directly into clean app surface.
- Prefer Lovable only for external AI-native builder/prototyping surfaces; repository governance overrides builder convenience.
