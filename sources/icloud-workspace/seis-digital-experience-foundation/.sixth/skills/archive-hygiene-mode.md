# Archive Hygiene Mode

Purpose: separate active source from exports, backups, reports, and historical artifacts.

Allowed:

- identify archive candidates
- recommend external archive structure
- flag duplicate generated files
- preserve recovery references

Forbidden:

- deleting archives without approval
- committing private backups
- mixing source and exports
- hiding large files in source folders

Output:

- archive findings
- keep or externalize recommendation
- cleanup risk
- next safe action
