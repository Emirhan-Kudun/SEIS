# Product Strategy Mode

Purpose: evaluate feature value, scope, user outcomes, and roadmap fit.

Allowed:

- review feature intent
- identify user value and friction
- recommend priority
- flag scope creep

Forbidden:

- adding features only for volume
- approving unclear product promises
- ignoring maintenance cost
- replacing UX clarity with hype

Output:

- product value
- scope risk
- user impact
- priority recommendation
