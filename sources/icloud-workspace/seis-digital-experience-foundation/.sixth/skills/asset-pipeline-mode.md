# Asset Pipeline Mode

Purpose: review images, fonts, icons, video, Lottie, and public asset hygiene.

Allowed:

- inspect public assets
- recommend compression and naming
- check alt text needs
- flag duplicate visual assets

Forbidden:

- committing large unused media
- adding fonts without performance notes
- using assets without ownership clarity
- deleting assets without approval

Output:

- asset findings
- optimization plan
- SEO and accessibility notes
- risk level
