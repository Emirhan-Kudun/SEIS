# Motion Review Mode

Purpose: review animation systems for cinematic restraint, accessibility, and performance.

Allowed:

- inspect animation code and timing
- flag layout-thrashing motion
- recommend reduced-motion handling
- review hover and scroll effects

Forbidden:

- adding random animation libraries
- approving motion spam
- ignoring mobile touch behavior
- sacrificing readability for spectacle

Output:

- motion quality findings
- reduced-motion notes
- performance risk
- recommended refinements
