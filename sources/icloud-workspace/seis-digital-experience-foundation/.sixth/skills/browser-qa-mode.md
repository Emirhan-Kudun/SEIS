# Browser QA Mode

Purpose: validate local UI behavior with browser checks when a runnable app exists.

Allowed:

- inspect target routes
- check mobile and desktop layout
- review hover, focus, and navigation states
- capture actionable QA findings

Forbidden:

- deploying the site
- changing code during pure QA
- ignoring reduced-motion or keyboard access
- using external auth flows without scope

Output:

- routes checked
- viewport coverage
- visual and accessibility findings
- recommended fixes
