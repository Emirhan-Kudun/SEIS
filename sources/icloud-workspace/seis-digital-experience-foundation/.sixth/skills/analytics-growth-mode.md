# Analytics Growth Mode

Purpose: review conversion measurement, growth loops, and privacy-safe analytics.

Allowed:

- define useful events
- map CTA and funnel signals
- flag vanity metrics
- recommend privacy-safe measurement

Forbidden:

- tracking sensitive data
- adding analytics SDKs without approval
- measuring everything without a goal
- using dark-pattern growth tactics

Output:

- measurement plan
- privacy risks
- event candidates
- next safe action
