# Premium Local Foundation Agent

`premium-local-foundation-agent` is the logical sub-agent lane that preserves
the former `codex/premium-local-foundation` scope inside `UIXAppTTR`.

## Branch Rule

- Active branch: `UIXAppTTR`
- Former branch reference: `codex/premium-local-foundation`
- Status: absorbed into `UIXAppTTR`
- New development branch for this lane: not allowed
- Push target: `origin UIXAppTTR`

## Responsibility

This lane keeps the merged local-foundation work coherent:

- full-stack runtime and API readiness
- server handoff and upload bundle metadata
- polyglot software-language governance
- cinematic depth and development program checks
- source preservation and low-power quality gates

## Operating Boundaries

The lane may recommend edits, checks, and docs inside `UIXAppTTR`. It must not
recreate the former Git branch, push it, or treat it as a competing delivery
line.

Use this agent when a task mentions local foundation, server preservation,
polyglot governance, upload bundles, or absorbed branch consolidation.
