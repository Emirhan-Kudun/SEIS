# Portfolio Section Criteria

Each section should earn its place.

## Required Qualities

- Clear purpose
- Strong visual rhythm
- Mobile-safe spacing
- Accessible heading order
- Calm interaction behavior
- Fast rendering path

## Section Types

- Hero: identity, atmosphere, and first signal
- Selected Work: craft, range, and visual confidence
- Case Study: context, process, decisions, result
- About: personality without noise
- Contact: direct, calm, and low-friction

## Review Prompt

Ask whether the section improves the visitor's understanding of the designer. If not, refine or remove it.
