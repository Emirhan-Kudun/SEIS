## Core Principle Application

### Before ANY Change

Ask these questions:

1. **Does this improve clarity?**
   - Reduced ambiguity?
   - Better communication?
   - Clearer structure?

2. **Does this preserve/enhance rhythm?**
   - Maintains visual flow?
   - Improves pacing?
   - Supports emotional continuity?

3. **Does this strengthen atmosphere?**
   - Adds appropriate mood?
   - Maintains calm tone?
   - Supports immersion?

4. **Does this respect restraint?**
   - Minimal necessary addition?
   - No excess?
   - Refined execution?

5. **Does this communicate care?**
   - Precision evident?
   - Thoughtful implementation?
   - Quality execution?

If the answer is **NO** to any critical question, **reconsider the change**.

## Emergency Protocol

### If Clarity is Disrupted

1. Stop other work
2. Identify disruption source
3. Restore clarity
4. Test restoration
5. Document what happened
6. Prevent recurrence

### If Rhythm is Broken

1. Pause user-facing changes
2. Diagnose rhythm issue
3. Restore smooth pacing
4. Verify user experience
5. Document the fix
6. Update guidelines if needed

### If Atmosphere is Lost

1. Assess emotional impact
2. Identify atmosphere disruption
3. Refine implementation
4. Re-establish calm tone
5. Verify emotional continuity
6. Update approach if needed
