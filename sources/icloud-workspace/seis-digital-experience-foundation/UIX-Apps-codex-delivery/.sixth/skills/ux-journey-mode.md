# UX Journey Mode

Purpose: review navigation, CTAs, user flow, state coverage, and friction.

Allowed:

- inspect flows and section order
- identify missing empty, loading, error, or success states
- recommend CTA hierarchy
- flag cognitive overload

Forbidden:

- adding complex flows without need
- hiding key actions on mobile
- creating hover-only UX
- approving unclear next steps

Output:

- journey map findings
- friction points
- missing states
- next safe action
