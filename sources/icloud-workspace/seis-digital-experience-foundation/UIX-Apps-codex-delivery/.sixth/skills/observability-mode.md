# Observability Mode

Purpose: review monitoring, logs, analytics, and error visibility.

Allowed:

- inspect logging patterns
- recommend privacy-safe events
- flag missing error boundaries or reporting notes
- review noise level

Forbidden:

- logging secrets
- tracking sensitive data
- adding monitoring SDKs without approval
- creating vanity analytics

Output:

- observability gaps
- privacy risks
- recommended signals
- next safe action
