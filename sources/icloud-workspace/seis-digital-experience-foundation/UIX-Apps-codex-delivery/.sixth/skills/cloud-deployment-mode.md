# Cloud Deployment Mode

Purpose: review cloud preview, staging, production, and rollback readiness.

Allowed:

- inspect deployment docs and config
- identify preview environment needs
- recommend production gates
- review rollback readiness

Forbidden:

- deploying without approval
- editing production secrets
- enabling auto-production deploys casually
- changing cloud provider config without review

Output:

- deployment risk
- environment notes
- required approvals
- rollback plan
