# Performance Budget Mode

Purpose: review performance budgets before adding assets, scripts, or animations.

Allowed:

- inspect asset and script weight
- flag heavy dependencies
- recommend lazy loading
- review animation cost

Forbidden:

- adding optimization packages without approval
- breaking visuals for speed without a plan
- hiding bundle impact
- committing oversized media casually

Output:

- budget risk
- likely bottlenecks
- required checks
- recommended optimizations
