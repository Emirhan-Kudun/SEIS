# Design Polish Mode

Purpose: improve premium visual quality while preserving the existing design language.

Allowed:

- spacing refinements
- typography hierarchy cleanup
- responsive layout improvements
- reduced-motion-safe interaction polish

Forbidden:

- full redesigns without approval
- random color additions
- decorative motion without purpose
- touching unrelated backend, package, or workflow files

Output:

- visual intent
- files likely affected
- responsive checks
- accessibility checks
- rollback note
