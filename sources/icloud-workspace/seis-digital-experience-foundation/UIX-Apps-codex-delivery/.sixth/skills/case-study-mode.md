# Case Study Mode

Purpose: improve portfolio project storytelling and proof structure.

Allowed:

- review project sections
- recommend challenge, process, solution, and result framing
- flag missing proof points
- improve scanability

Forbidden:

- inventing fake metrics
- using generic placeholder claims
- copying another portfolio structure directly
- overloading case studies with noise

Output:

- story gaps
- proof gaps
- recommended structure
- copy risks
