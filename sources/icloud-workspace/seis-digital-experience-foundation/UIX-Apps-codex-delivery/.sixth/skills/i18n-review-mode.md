# I18n Review Mode

Purpose: protect TR/EN/FR/IT/DE localization coverage and layout safety.

Allowed:

- inspect translation files
- flag missing keys
- review hard-coded copy
- check longer-copy layout risk

Forbidden:

- removing languages
- machine-translating critical brand copy without review
- changing keys without migration notes
- ignoring overflow risk

Output:

- language coverage
- missing keys
- layout risks
- next safe action
