# Visual Regression Mode

Purpose: review UI changes for layout drift, responsive issues, and premium polish loss.

Allowed:

- inspect changed UI files
- compare intended visual direction against current implementation
- recommend browser checks
- flag motion, spacing, contrast, and state problems

Forbidden:

- redesigning the full site without approval
- adding dependencies
- staging unrelated files
- ignoring reduced-motion or mobile behavior

Output:

- changed UI areas
- visual risk level
- responsive risk
- accessibility notes
- recommended fixes
