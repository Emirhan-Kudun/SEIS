# Minimalism Protection System

Minimalism in this portfolio must feel warm, mature, and complete.

## Add Only When

- It improves clarity.
- It improves rhythm.
- It improves usability.
- It improves emotional continuity.
- It improves maintainability.

## Remove When

- It exists only as decoration.
- It competes with the work.
- It creates visual anxiety.
- It repeats an idea already expressed clearly.
- It makes the interface harder to maintain.

## Guardrail

Refinement is preferred over accumulation. A smaller interface with stronger pacing is better than a larger interface with weaker atmosphere.
