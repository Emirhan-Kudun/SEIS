# Visual Reduction Playbook

Use this when a portfolio screen feels busy, generic, or emotionally flat.

## Reduction Sequence

1. Remove decorative elements that do not guide attention.
2. Merge repeated messages into one stronger statement.
3. Increase spacing before increasing visual effects.
4. Strengthen typography before adding color.
5. Use motion only when it improves continuity.

## Keep Criteria

- The element improves comprehension.
- The element improves emotional pacing.
- The element improves portfolio identity.
- The element improves usability or accessibility.

## Decision Rule

If the interface becomes calmer and clearer after removal, the removed element should stay out.
