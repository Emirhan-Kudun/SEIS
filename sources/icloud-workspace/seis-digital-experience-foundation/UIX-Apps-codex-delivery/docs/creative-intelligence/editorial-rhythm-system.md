# Editorial Rhythm System

The portfolio should use editorial rhythm to shape attention.

## Rhythm Rules

- Use fewer sections with stronger pacing.
- Keep headings restrained and readable.
- Let images and text alternate with quiet confidence.
- Avoid dense decorative clusters.
- Preserve visual silence between major ideas.

## Content Pattern

Use this sequence for premium project storytelling:

1. Intent
2. Context
3. Visual Direction
4. Craft Decisions
5. Result

## Mobile Rule

Mobile should not feel compressed. It should feel like the same editorial space, scaled with care.
