# Security Policy

All projects follow strict security guidelines:

- 🔐 Regular dependency audits
- 🔒 Input validation & sanitization
- 🛡️ HTTPS enforcement
- 🔑 Secure authentication (JWT, OAuth2)
- 📊 Regular security scans
- ⚠️ Responsible disclosure

**Security Contact**: security@seis.dev

See individual project SECURITY.md files for specific policies.
